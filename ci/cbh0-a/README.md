# CBH0-A frontend debt baseline

This directory records the normalized Node 22.18.0 baseline captured at commit
`e7c94291c6488fd922dcd42cba485555cb35581f`.

These files are regression ratchets, not declarations that the repository is
globally green. New or substituted failures must be rejected. Resolved failures
are improvements and must not silently return. Baseline changes require an
explicit, reviewed maintenance slice.
